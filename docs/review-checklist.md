# Review checklist

- [ ] Fixture is synthetic and contains no secrets or user data.
- [ ] Fixture ID is stable and unique.
- [ ] Source and version are recorded where claims depend on external behavior.
- [ ] Snapshot/delta semantics are explicit.
- [ ] Parent/child and retry aggregation is not ambiguous.
- [ ] Unknown, zero, missing, and unsupported are not conflated.
- [ ] Estimated cost is distinguished from provider-reported or invoice-backed cost.
- [ ] Expected behavior is justified and not overstated as a standard.
- [ ] Validator and tests were run; results are reported accurately.
- [ ] Scope remains interoperability research, not billing or enforcement.
