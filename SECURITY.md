# Security policy

## Scope

This repository contains synthetic draft fixtures, documentation, and/or offline validation scripts. It is not a production service. Do not submit real credentials, personal data, customer payloads, private benchmark material, or production secrets.

## Reporting a vulnerability

Please do **not** open a public issue for an undisclosed security vulnerability.

1. Use GitHub's **Security → Report a vulnerability** private reporting flow for this repository if it is enabled.
2. If private reporting is unavailable, contact the repository maintainer through a private contact channel listed on the maintainer's GitHub profile and request a secure disclosure route. Do not publish details while waiting.
3. Include the affected repository/path, impact, minimal reproduction, relevant commit/ref, and any proposed mitigation. Redact secrets and personal data.

## Response expectations

This project is maintained on a best-effort basis. No response-time or remediation SLA is currently promised. Please allow maintainers time to triage and coordinate a fix before public disclosure.

## Safe testing

Only test the repository's offline fixtures and validator scripts. Do not test against third-party systems, live agents, hosted services, or real user data without explicit authorization.
